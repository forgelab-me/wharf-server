Private registries

Any number of registries, of any type — Docker Hub, GHCR, GitLab, Azure Container Registry, or a self-hosted Harbor/Nexus/Distribution. Each credential is used two ways: the image auto-update check (cf. a stack's Images policy) authenticates with it against that host, and the agent logs in with it before pulling on every deploy — so a stack's compose file can reference a private image on any host configured here, whether the stack lives in Git or was authored in Wharf.
