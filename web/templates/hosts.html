Add an agent

Copy this command onto the target host — the controller's fingerprint is already filled in. The agent will show up above as pending approval as soon as it connects for the first time.

docker run -d \
  --name wharf-agent \
  --restart unless-stopped \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/wharf-agent/identity:/var/lib/wharf-agent/identity \
  -v /opt/wharf-agent/stacks:/opt/wharf-agent/stacks \
  ghcr.io/forgelab-me/wharf-agent:latest \
  --controller={{.ControllerAddr}} \
  --controller-fingerprint={{.ControllerFingerprint}}
{{end}}
