Download a backup

A single file with everything that makes this controller work: every stack, host, user and audit entry, every stored secret and private key, and the controller's own identity — the certificate every enrolled agent has already pinned. Restoring it onto a fresh box lets existing agents reconnect without re-enrolling. Taken live, safe to run any time; doesn't pause or lock anything.

Without one, the downloaded file contains every secret and private key in plain text — treat it accordingly. With one, the whole archive is encrypted (age's passphrase mode) and useless without it; there is no recovery if you lose the passphrase.

Restore from a backup

This replaces everything on this controller — every stack, user, secret and the controller's identity — with what's in the file. The current data isn't deleted, only set aside with a timestamp suffix in the data directory, but it stops being what the app reads from the moment this applies. A restore is staged, not immediate: after uploading, restart the controller (docker compose up -d --force-recreate, or an equivalent restart) for it to actually take effect.
