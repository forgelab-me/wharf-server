Backup destinations

Where the backups of your volumes are written: a SMB (CIFS) share. Wharf keeps the backups in an encrypted restic repository on it, one per host, so the share only ever holds ciphertext. A destination is set up once and used by any number of jobs; the share and repository passwords are write-only and are never shown again, except the repository password, which you can reveal to restore somewhere else.
